### `✦ um pouco sobre mim ✦`

</div>

Estou **migrando pra área de tecnologia**, estudando programação e aprendendo lógica de programação na prática.

Uso IA (como o Claude) como parceira de desenvolvimento — pra entender melhor cada passo e construir coisas reais enquanto aprendo, em vez de só ler teoria.

Meu projeto principal até agora é o **MeuTreino / UltronFit**, um SaaS completo de treinos que construí do zero — da ideia até estar em produção, sendo usado de verdade.

Sou curioso por natureza: gosto de aprender construindo, testando e ajustando, sempre com um projeto novo na cabeça.
